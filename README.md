# Chord Canvas｜和弦情緒實驗室 — Web App 規格書

**作業主題：** 用 Vibe Coding 做出一個互動網頁  
**作品類型：** 音樂創作／教育型互動 Web App  
**成果形式：** 一個可直接開啟的 `index.html`，包含 HTML、CSS 與 JavaScript，不需後端及額外套件。

## 一、作品發想與動機

我對音樂理論和數位音樂感興趣，因此想做一個不用先學會複雜音樂軟體，也能快速把「情緒」轉化為和弦的網頁。我希望讓使用者透過一個直覺的操作介面，從不同情緒的和弦範例開始，自己修改調性、順序與速度，再直接聆聽結果。

這個網站不是 AI 音樂生成模型；它使用預先設計的和弦進行、音樂理論規則和瀏覽器音訊合成，重點是用 AI 輔助寫程式，將想法變成可操作的作品。

## 二、目標使用者與使用情境

- **目標使用者：** 對音樂好奇的初學者、想試聽和弦進行的人，以及需要音樂創作靈感的學生。
- **情境 1：** 使用者選擇「夜色」，網站自動產生小調和弦進行，按播放即可聆聽。
- **情境 2：** 使用者切換到 F 小調，從七個自然三和弦中挑選和弦，試著創作自己的四個和弦。
- **情境 3：** 使用者調整 BPM、移動順序、複製和弦名稱，將結果記錄到筆記裡。

## 三、功能規格

| 編號 | 功能 | 互動與預期結果 |
|---|---|---|
| F01 | 情緒預設 | 點選「明亮／夢幻／夜色／平靜」，套用四種不同的和弦進行；必要時自動切換為大調或小調。 |
| F02 | 選擇調性 | 提供 12 個主音與大調／自然小調，共 24 種調性設定，更新所有和弦名稱及音高。 |
| F03 | 和弦調色盤 | 顯示所選調性內的七個自然三和弦，包含羅馬級數、和弦名稱及和弦類型。 |
| F04 | 加入和弦 | 點選和弦卡片中的「＋」，加入和弦進行，最多八個；滿八個時顯示提醒。 |
| F05 | 編輯順序 | 在和弦進行卡片上按左右箭頭移動；按 × 刪除；按清空移除全部。 |
| F06 | 聲音播放 | 點「播放和弦進行」，瀏覽器利用 Web Audio API 合成聲音；每個和弦四拍、依序播放，同步標示播放位置；可停止。 |
| F07 | 單獨試聽 | 點和弦卡右上角的 ▶，可單獨聽該和弦。 |
| F08 | 速度調整 | 使用滑桿選擇 60–160 BPM；播放每格的長度依 BPM 計算。 |
| F09 | 隨機靈感 | 按「隨機靈感」，從符合目前調式的和弦進行範例中隨機挑選一組。 |
| F10 | 複製配方 | 複製調性、BPM、羅馬級數及和弦名稱的純文字摘要。 |
| F11 | 自動保存 | 利用 `localStorage` 保存主音、調式、速度與和弦進行，重新開啟同一網站可恢復。需允許瀏覽器儲存網站資料。 |
| F12 | 響應式排版 | 桌機版為左右兩欄；手機版改為單欄，按鈕與卡片可觸控操作。 |

## 四、頁面設計與互動流程

### 視覺風格

採深色夜空與柔和珊瑚粉為主色，搭配極簡卡片、漸層球體裝飾和播放中音量條動畫。希望營造「音樂實驗室」的氛圍，而不是一般制式作業網頁。

### 頁面區塊

1. **主視覺：** 網站名稱、作品概念和特色。
2. **01 找一種心情：** 四種情緒預設卡片。
3. **02 設定調性與節奏：** 主音、Major／Minor、BPM。
4. **03 和弦調色盤：** 七個和弦，可加入或個別試聽。
5. **04 你的和弦進行：** 最多八格的進行編輯區、播放控制和配方摘要。

### 主要操作流程

開啟網頁 → 選擇情緒 → 調整調性和 BPM → 選擇或修改和弦 → 點播放聆聽 → 視需要複製配方。沒有選擇情緒也能直接從調色盤開始。

## 五、音樂與技術規則

- 大調採用音階半音間隔 `[0, 2, 4, 5, 7, 9, 11]`；自然小調採用 `[0, 2, 3, 5, 7, 8, 10]`。
- 每級三和弦取該級、上方三度及五度的音，顯示級數與和弦種類。例如 F 自然小調的 `i–VI–III–VII` 為 `Fm–D♭–A♭–E♭`。
- 音訊透過 Web Audio API 中的 `OscillatorNode` 與 `GainNode` 產生，不依賴音樂檔或外部伺服器。
- 單一和弦為四拍；每個和弦播放秒數計算式為 `4 × 60 / BPM`。
- 音樂可在支援 Web Audio API 的現代瀏覽器播放；瀏覽器一般要求使用者先點擊播放按鈕才能發聲。
- **技術架構：** HTML 結構、原生 CSS、原生 JavaScript、`localStorage`，所有內容包含在 `index.html`。
- **限制：** 不提供真實鋼琴音色、MIDI 匯出、AI 模型生成或雲端跨裝置同步；情緒只是創作靈感分類，不是精確的情緒偵測。

## 七、Vibe Coding 與 AI 協作修改紀錄

1. **需求規劃：** 先確認作業必須有具體規格、實際互動功能、單檔 `index.html` 並能部署到 GitHub Pages，因此選擇不需要後端的音樂互動工具。
2. **初版實作：** 請 AI 將情緒預設、調性與七個自然三和弦轉換為可點擊的 UI，並使用 Web Audio API 產生聲音，而不是只展示靜態文字。
3. **功能完善：** 補上最多八格的編輯區、左右換位、單獨試聽、播放高亮、隨機靈感、複製與自動儲存，使網站更像真正可用的小工具。
4. **測試與修正：** 透過瀏覽器自動化操作測試按鈕、調性、和弦編輯、播放與手機排版；手機版調式按鈕出現擁擠情況，因此調整窄螢幕的欄位排列。再次確認 JavaScript 語法及畫面沒有明顯錯誤。
